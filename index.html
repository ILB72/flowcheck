FlowCheck플로우체크

논문: 트래픽 메타데이터를 활용한 IoT 기기 분류 모델의 성능 평가 및 외부 기기 적용 시 분류 경향 분석

IoT 보안을 처음 배우는 사람이 기기를 눌러 보면, 이 앱이 논문의 결과(등록된 기기는 98.19%로 맞히지만, 등록되지 않은 PC 트래픽은 56.2%가 BelkinCamera 한 기기로 몰림)를 보여 준다.

처음이라면 이 순서로

  1. 등록 = 이 모델이 학습한 IoT 기기 5종입니다(논문 표현: 학습에 포함된 기기. 그 밖은 포함되지 않은 기기이고, 모델은 5종 안에서만 고르는 '폐쇄 집합'입니다).
  2. 등록된 기기는 얼마나 잘 맞힐까? → 아래 작업 ①에서 기기를 눌러 보세요.
  3. 등록되지 않은 기기(내 PC)는 어떻게 분류될까? → 작업 ②를 한 단계씩 따라가 보세요.

용어 Flow = 주고받은 통신 한 건 단위 · 강제 분류 = 모르는데도 억지로 하나를 고름 · 쏠림 = 한 기기로 몰림 · 정확도 = 맞힌 수 ÷ 전체 · 가설 1·2 = 논문이 확인하려던 두 가지 주장(가설 1: 정확도 90% 이상, 가설 2: 등록되지 않은 기기도 5종에 고르게 나뉘지 않는다)

1 등록된 기기 확인

기기를 눌러 보세요. 이 모델이 그 기기의 트래픽을 얼마나 맞히는지 논문 값으로 보여 줍니다.

전체 정확도 98.19% (12,584 / 12,816, 논문 §4.1)

    논문 표 전체 보기 (표 2 성능표 · 표 3 혼동행렬)

    2 등록되지 않은 기기(PC) 따라가기 핵심 작업

    논문이 등록되지 않은 PC의 트래픽을 넣어 본 과정을 4단계로 따라갑니다. 「다음」을 눌러 보세요.

    단계 1 / 4

    3 내 정확도 입력

    위 98.19%에 이어서, 내 모델의 정확도를 논문 기준(90% 이상)과 비교해 보세요.

    정확도는 어디서 얻나요? 모델 평가 결과의 맞힌 수 ÷ 전체 수 × 100 (논문: 12,584 ÷ 12,816). 정답과 일치한 건수를 센 값입니다.

    참고: 논문 값 98.19% (12,584 / 12,816, 논문 §4.1)

    논문의 결론 — 그래서 필요한 것

    1. 등록되지 않은 기기를 가려내는 기준이 필요 — 모르는 기기는 '알 수 없음(Unknown)'으로 분리해야 함 (§5.1·§6)
    2. 시간·세션 기준 검증이 필요 — 무작위로 나눠 평가해 성능이 높게 나왔을 수 있음 (§5.3·§6)
    3. 왜 BelkinCamera로 몰리는지는 아직 단정 불가 — 영상 스트리밍·대용량 전송 같은 트래픽 특성이 비슷해서일 수 있다는 논문의 추정이 있으나 확정은 아님. 후속 과제: 특징 기여도(XAI) 분석 (§5.2·§6)

    이 앱은 등록되지 않은 기기를 가려내는 기능이 없고, 기준값도 논문에 없어 만들지 않았습니다.

    논문이 밝힌 해석의 한계

    1. 단일 PC에서 약 3분간 캡처한 트래픽이다.
    2. 무작위 분할을 사용해 같은 세션의 Flow가 학습·평가에 섞였을 수 있다(세션 누수 가능).
    3. 특징 기여도 분석이 없어 쏠림의 원인을 단정할 수 없다.
    4. AmazonEcho, BelkinCamera, TPLinkSmartPlug, NetatmoWeatherStation, SamsungSmartThings 5종 기기에 한정된다.
    내 결과로 확인해 보기 (선택)

    내 모델의 분류 결과가 있을 때만 쓰는 기능입니다. 위 세 작업은 이 영역 없이도 끝낼 수 있습니다.

    내 결과를 얻는 방법 4단계

    1. ① 캡처Wireshark로 약 3분
    2. ② Flow 집계scapy로 8개 특징 집계
    3. ③ 분류 실행랜덤 포레스트, 5종
    4. ④ 건수 입력클래스별 건수를 아래에

    8개 특징: srcPort, dstPort, ipProto, srcNumPackets, dstNumPackets, srcPayloadSize, dstPayloadSize, flowDuration

    결과 파일 만드는 코드 예시

    1) 설치 (터미널)

    pip install pandas scikit-learn scapy

    2) 분류 결과 저장 (Python)

    import pandas as pd
# model: 논문 설정으로 학습한 RandomForestClassifier
# X: 새 트래픽의 특징표(8개 특징을 원-핫으로 변환한 것)
# train_columns: 학습 때 만든 특징 컬럼 목록(학습에 쓴 특징표의 컬럼)
X = X.reindex(columns=train_columns, fill_value=0)
pd.DataFrame({"predicted": model.predict(X)}).to_csv("result.csv", index=False)

    모델 학습은 논문의 설정을 따른다(논문 PDF). FlowCheck는 모델을 학습·실행하지 않고 result.csv의 건수만 센다.

    분류 결과 건수 입력 → 점유율 점검

    쏠림 점검은 등록되지 않은 기기(예: 내 PC)의 트래픽을 분류한 결과에 쓰는 도구입니다. 등록된 5종 기기 자신의 트래픽 분류에는 정확도(작업 ③)를 보세요.

    모델이 각 기기로 분류한 Flow(통신 한 건) 건수를 0 이상의 정수로 입력하세요. 분류 결과 CSV(predicted 열)가 있으면 바로 집계할 수 있습니다.

    CSV로 채우기

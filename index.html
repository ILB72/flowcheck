FlowCheck플로우체크

논문: 트래픽 메타데이터를 활용한 IoT 기기 분류 모델의 성능 평가 및 외부 기기 적용 시 분류 경향 분석

IoT 기기 분류 결과를 받은 보안 입문자가 클래스별 건수를 입력하면, 이 앱이 논문 기준(정확도 90%, 클래스 20% 내외)으로 한쪽 쏠림(강제 분류) 경고와 해석의 한계를 보여 준다.

1 예시 불러오기

논문에서 학습에 없던 PC 트래픽 697 Flow를 분류했을 때의 분포입니다.

2 내 결과 입력

모델이 각 기기로 분류한 Flow 건수를 0 이상의 정수로 입력하세요.

3 정확도 확인

참고: 논문 값 98.19% (12,584 / 12,816)

논문이 밝힌 해석의 한계

  1. 단일 PC에서 약 3분간 캡처한 트래픽이다.
  2. 무작위 분할을 사용해 같은 세션의 Flow가 학습·평가에 섞였을 수 있다(세션 누수 가능).
  3. 특징 기여도 분석이 없어 쏠림의 원인을 단정할 수 없다.
  4. AmazonEcho, BelkinCamera, TPLinkSmartPlug, NetatmoWeatherStation, SamsungSmartThings 5종 기기에 한정된다.
FlowCheck는 모델을 학습·실행하지 않고, 입력한 숫자를 논문 기준과 비교만 합니다. 논문 원자료는 포함하지 않습니다.

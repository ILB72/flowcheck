# 예시 CSV 출처

`sample_paper_pc.csv`(화면 이름: 등록되지 않은 기기(PC) 논문 사례)는 FlowCheck를 위해 **합성**한 분류 결과 라벨 목록입니다.

- 열 `predicted`, 697행. 논문 표 4의 PC 트래픽 697 Flow 분류 건수(BelkinCamera 392, AmazonEcho 186, SamsungSmartThings 100, NetatmoWeatherStation 18, TPLinkSmartPlug 1)를 라벨 목록으로 풀어 쓴 것이며 행 순서는 섞었습니다.
- 분류 결과의 건수만 필요하므로 트래픽 자체는 들어 있지 않습니다. UNSW-IoTraffic 원자료, 실제 트래픽, 식별자(IP·MAC 등)도 포함하지 않습니다.

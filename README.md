# FlowCheck (플로우체크)

IoT 기기 분류 결과를 받은 보안 입문자가 기기별 분류 건수를 입력하면, 이 앱이 논문 기준(정확도 90%, 각 기기 20% 내외)으로 등록되지 않은 기기를 한 기기로 몰아 분류(강제 분류)하는지 알려 주고 해석의 한계를 보여 준다.

기반 논문: 트래픽 메타데이터를 활용한 IoT 기기 분류 모델의 성능 평가 및 외부 기기 적용 시 분류 경향 분석

## 화면

포트폴리오 사이트와 같은 계열의 디자인이다(포레스트 그린 + 앰버 보조색 토큰, 알약형 버튼·링크, 둥근 카드, 격자 무늬 히어로). 상단 히어로(FlowCheck 로고타입, 논문 제목, 앱 한 문장, 포트폴리오로 돌아가기·GitHub 저장소 링크) 아래에 "이 앱이 보여 주는 것" 3줄 설명과 용어 풀이, 4단계 가이드가 있고 그 아래에 번호 배지 카드 3개(예시 / 내 결과 / 정확도)와 논문이 밝힌 한계 블록이 이어진다. 기기가 다크 모드이면 자동으로 어두운 톤으로 바뀐다. "한 기기로 몰림" 경고는 색 띠·아이콘·텍스트로, 정확도 판정은 작은 '통과'/'미달' 배지로 표시하며, 논문의 결론 블록(등록되지 않은 기기를 가려내는 기준·시간/세션 기준 검증·특징 기여도 분석이 필요하다는 내용)이 예시 아래에 항상 보이고, 막대는 점유율 내림차순에 최다 클래스만 강조색이다. 외부 폰트·CDN은 쓰지 않는다.

## 내 결과를 얻는 방법 (화면 상단 4단계 가이드)

① PC 트래픽 약 3분 캡처 → ② Flow로 묶어 8개 특징 계산(srcPort, dstPort, ipProto, srcNumPackets, dstNumPackets, srcPayloadSize, dstPayloadSize, flowDuration) → ③ 랜덤 포레스트로 5종 기기 분류 → ④ 클래스별 건수를 FlowCheck에 입력. 이 앱은 ①~③을 실행하지 않는다.

## 테스트 자료 (`samples/`)

분류 결과 라벨 CSV(헤더 `predicted` 필수, 정답 `actual` 열은 선택). **합성 예시 데이터**이며 실제 트래픽·개인정보가 없다.

| 파일 | 내용 |
|---|---|
| `sample_known_devices.csv` | 등록된 기기 예시(합성, 논문의 실제 분류 결과가 아님): 열 `actual,predicted`, 100행(기기별 20행), 98행이 정답과 일치·2행 불일치 → 정확도 98.00%, 논문 가설 1(정확도 90% 이상) 통과 |
| `sample_paper_pc.csv` | 등록되지 않은 기기(PC) 논문 사례 697행(BelkinCamera 392 등) → BelkinCamera 56.2%, "한 기기로 몰림" 경고 |

`actual` 열이 있는 파일은 정확도(작업 3)를 자동 계산해 논문 가설 1(정확도 90% 이상) 통과/미달을 보여 주고(예측 분포 막대는 비교용으로만 보여 주며 쏠림 판정은 하지 않는다. 쏠림 점검은 등록되지 않은 기기용), `predicted`만 있으면 클래스별 건수를 채워 점유율·쏠림을 점검한다. 작업 2에서 "바로 불러오기" 버튼, 파일 선택, 붙여넣기로 집계할 수 있다. 5종 밖의 클래스명은 "알 수 없는 클래스 N건"으로 표시하고, 헤더 없음·빈 파일·5MB 초과는 안내 문구를 보여 준다. 파일은 브라우저 안에서만 처리되며 서버로 전송되지 않는다.

## 논문 결과를 앱에서 쓰는 방법

| 기능 | 사용한 논문 수치 |
|---|---|
| 1. 예시 불러오기 | 두 장면을 위→아래로 보여 준다. ⓐ 등록된 기기(5종)의 트래픽 — 잘 맞힘(내부 테스트, 테스트 조건 표기): 정확도 98.19%(12,584/12,816, §4.1), 표 3 열 합계로 계산한 예측 분포 막대(Echo 20.9%, Camera 20.0%, Netatmo 20.0%, SmartThings 19.3%, Plug 19.7%), 표 2 성능표, 접이식 표 3 혼동행렬(SamsungSmartThings→AmazonEcho 126건 강조). 기기 이름은 전체 이름으로 통일. ⓑ 등록되지 않은 기기(PC)의 트래픽 — 등록된 기기로 잘못 분류됨(강제 분류), 697 Flow 분포: BelkinCamera 392(56.2%), AmazonEcho 186(26.7%), SamsungSmartThings 100(14.3%), NetatmoWeatherStation 18(2.6%), TPLinkSmartPlug 1(0.1%). 56.2%는 FPR이 아니라 논문이 정의한 "강제 분류 비율"이다. |
| 2. 내 결과 입력 | 논문 가설 2 기준(5종에 똑같이 나뉘면 각 20%). 가장 많이 몰린 기기의 점유율과 20%의 차이(%p)를 계산하고, 모든 기기가 20%±10%p 안이면 "고르게 나뉨 — 다만 등록되지 않은 트래픽이라면 어느 쪽이든 제대로 된 분류가 아닙니다(§5.1)"(가설 2 기각 조건), 아니면 "한 기기로 몰림 — 등록되지 않은 트래픽을 억지로 분류한 모양(논문 가설 2와 같은 양상)"으로 표시한다. ±10%p는 '내외'를 앱에서 해석한 값이며 논문 수치가 아니다. |
| 3. 정확도 확인 | 논문 가설 1 기준(정확도 90% 이상). 참고값 98.19%(12,584/12,816). |
| 한계 안내(항상 표시) | 단일 PC·약 3분 캡처 / 무작위 분할로 세션 누수 가능 / 특징 기여도 분석 없어 쏠림 원인 단정 불가 / 5종 기기 한정 |

모델 학습·추론은 하지 않으며, 논문에 없는 기준(예: Unknown 판정 임계값)은 만들지 않았다. 논문 원자료는 포함하지 않는다.

## 실행 방법

- `index.html`을 더블클릭해 브라우저로 연다. 또는
- 이 폴더에서 `npx serve`를 실행한 뒤 표시된 주소로 접속한다.

빌드·서버·API 키·외부 CDN이 필요 없다. 환경 변수는 없다. Vercel 정적 배포(빌드 명령 없음, 루트 폴더 그대로)로도 동작한다.

## 사용 방법 3가지와 결과

쏠림 점검(작업 1·2)은 등록되지 않은 기기(예: 내 PC)의 트래픽을 분류한 결과에 쓰는 도구입니다. 등록된 5종 기기 자신의 트래픽 분류에는 정확도(작업 3)를 보세요. 모델에 "알 수 없음" 선택지가 없으면 어느 쪽으로 나누든 제대로 된 분류가 아니며(논문 §5.1), 몰림은 등록된 5종 안에서만 고르는 모델의 강제 분류입니다(논문 §4.2). 이 앱은 등록되지 않은 기기를 가려내는 기능을 제공하지 않습니다.

1. **예시 불러오기**: "논문 예시 불러오기" 버튼을 누른다 → 5개 클래스 막대 그래프(BelkinCamera 56.2% 등)와 "한 기기로 몰림 … 20%와의 차이 +36.2%p"가 나온다.
2. **내 결과 입력**: 클래스별 건수(0 이상 정수)를 입력하고 "점유율 확인"을 누른다 → 점유율 그래프와 "고르게 나뉨" 또는 "한 기기로 몰림"가 나온다. 빈칸·음수·소수·문자·전부 0이면 입력칸 아래에 안내 문구가 나온다. 예: `20 20 20 20 20` → 고르게 나뉨(제대로 분류됐다는 뜻은 아님).
3. **정확도 확인**: 정확도(%)를 입력하고 "확인"을 누른다 → 98.19는 "통과", 85는 "미달". 0~100 밖이나 문자는 안내 문구가 나온다.

## 출처와 이용 조건

- 논문: 트래픽 메타데이터를 활용한 IoT 기기 분류 모델의 성능 평가 및 외부 기기 적용 시 분류 경향 분석 (PDF: https://kms-portfolio-site.vercel.app/assets/논문_김민석_T10.pdf). 표 2(성능표)와 표 3(혼동행렬)은 논문에서 가져와 화면에 옮겼다(표 3 열 합계로 예측 분포를 계산).
- 원자료: UNSW-IoTraffic(UNSW Canberra), https://iotanalytics.unsw.edu.au/iottraces.html. 앱에 포함하지 않았다. 이용 조건은 해당 사이트에서 확인한다. 인용: Sivanathan et al. (2018), "Classifying IoT Devices in Smart Environments Using Network Traffic Characteristics", IEEE Transactions on Mobile Computing 18(8), 1745–1759.
- 모델·집계 설정(Wireshark 캡처, scapy Flow 집계, scikit-learn 랜덤 포레스트): 논문 본문과 논문 재현 스크립트.
- 예시 CSV 2개: FlowCheck를 위해 합성한 것(`samples/README.md` 참고). 등록된 기기 예시는 논문의 실제 분류 결과가 아니며, 등록되지 않은 기기(PC) 논문 사례는 표의 건수를 라벨로 풀어 쓴 것. 실제 트래픽·식별자 없음.
- 그림: 직접 만든 인라인 SVG. 외부 이미지·폰트·CDN 없음.
- CSV 집계는 코드 라벨(TPLinkPlug, NetatmoWeather, SmartThings)도 논문 표기로 인식한다.

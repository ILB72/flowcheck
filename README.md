# FlowCheck (플로우체크)

IoT 기기 분류 결과를 받은 보안 입문자가 클래스별 건수를 입력하면, 이 앱이 논문 기준(정확도 90%, 클래스 20% 내외)으로 한쪽 쏠림(강제 분류) 경고와 해석의 한계를 보여 준다.

기반 논문: 트래픽 메타데이터를 활용한 IoT 기기 분류 모델의 성능 평가 및 외부 기기 적용 시 분류 경향 분석

## 화면

상단 히어로(FlowCheck 로고타입, 논문 제목, 앱 한 문장) 아래에 번호 배지가 달린 카드 3개(예시 / 내 결과 / 정확도)와 논문이 밝힌 한계 블록이 이어진다. 밝은 리포트형이 기본이며, 기기가 다크 모드이면 자동으로 어두운 관제 콘솔 톤으로 바뀐다. 쏠림 경고는 색 띠·아이콘·텍스트로, 정확도 판정은 큰 '통과'/'미달' 배지로 표시한다. 막대는 점유율 내림차순이며 최다 클래스만 강조색이다.

## 논문 결과를 앱에서 쓰는 방법

| 기능 | 사용한 논문 수치 |
|---|---|
| 1. 예시 불러오기 | 학습에 없던 PC 트래픽 697 Flow 분포: BelkinCamera 392(56.2%), AmazonEcho 186(26.7%), SamsungSmartThings 100(14.3%), NetatmoWeatherStation 18(2.6%), TPLinkSmartPlug 1(0.1%). 56.2%는 FPR이 아니라 논문이 정의한 "강제 분류 비율"이다. |
| 2. 내 결과 입력 | 논문 H2 기준(각 클래스 20% 내외). 가장 큰 점유율과 20%의 차이(%p)를 계산하고, 모든 클래스가 20%±10%p 안이면 "고르게 분산(H2 기각 조건)", 아니면 "쏠림 있음(H2 채택 조건과 같은 양상)"으로 표시한다. ±10%p는 '내외'를 앱에서 해석한 값이며 논문 수치가 아니다. |
| 3. 정확도 확인 | 논문 H1 기준(정확도 90% 이상). 참고값 98.19%(12,584/12,816). |
| 한계 안내(항상 표시) | 단일 PC·약 3분 캡처 / 무작위 분할로 세션 누수 가능 / 특징 기여도 분석 없어 쏠림 원인 단정 불가 / 5종 기기 한정 |

모델 학습·추론은 하지 않으며, 논문에 없는 기준(예: Unknown 판정 임계값)은 만들지 않았다. 논문 원자료는 포함하지 않는다.

## 실행 방법

- `index.html`을 더블클릭해 브라우저로 연다. 또는
- 이 폴더에서 `npx serve`를 실행한 뒤 표시된 주소로 접속한다.

빌드·서버·API 키·외부 CDN이 필요 없다. 환경 변수는 없다. Vercel 정적 배포(빌드 명령 없음, 루트 폴더 그대로)로도 동작한다.

## 사용 방법 3가지와 결과

1. **예시 불러오기**: "논문 예시 불러오기" 버튼을 누른다 → 5개 클래스 막대 그래프(BelkinCamera 56.2% 등)와 "쏠림 경고 … 20%와의 차이 +36.2%p"가 나온다.
2. **내 결과 입력**: 클래스별 건수(0 이상 정수)를 입력하고 "점유율 확인"을 누른다 → 점유율 그래프와 "고르게 분산" 또는 "쏠림 경고"가 나온다. 빈칸·음수·소수·문자·전부 0이면 입력칸 아래에 안내 문구가 나온다. 예: `20 20 20 20 20` → 고르게 분산.
3. **정확도 확인**: 정확도(%)를 입력하고 "확인"을 누른다 → 98.19는 "통과", 85는 "미달". 0~100 밖이나 문자는 안내 문구가 나온다.
